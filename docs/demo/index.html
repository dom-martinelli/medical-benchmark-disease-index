A benchmark item can be indexed even when no model output is available. The explorer records these states rather than converting a whole-benchmark leaderboard score into a disease-specific score.

State 1

Item-level results

Disease-stratified scores can be calculated from stored outputs or item scores.
State 2

Aggregate only

A whole-benchmark score exists, but it cannot be disaggregated by disease.
State 3

Evaluable, not run

An answer key or rubric exists, but no reusable item-level result is attached.
