How to locate a HealthBench source item.

The public explorer intentionally shows HealthBench IDs and derived labels, but withholds the conversation text. The resolver maps the displayed hash to the original prompt ID and pinned source row.

1

Copy the displayed item ID

For example: healthbench-68ebc53be307db72.

python3 scripts/resolve_healthbench_item.py \
  healthbench-68ebc53be307db72

The command prints the original prompt_id, 1-based source row, pinned revision, raw source URL, and viewer link. Add --show-text only for local inspection; do not copy that output into the public explorer.

Run it yourself.

The repository includes the browser demo, redacted explorer data, Python app, source resolver, pipeline stages, prompts, and tests.

Run the prepared explorer locally

git clone https://github.com/dom-martinelli/medical-benchmark-disease-index.git
cd medical-benchmark-disease-index
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py

The included explorer Parquet files are redacted. HealthBench text is withheld in both the local app and the public demo.

Rebuild the index from source

python run.py
# Review data/pilot_labels.md, then explicitly approve:
python run.py --approve-pilot

Approval gate: the first command labels a 50-item pilot and stops. The full labeling pass does not begin until the second command is run.

What the index does and does not claim.

Condition and role labels for the original ten sources were assigned by an AI model and were not reviewed by a clinician. LiveClin's case diagnosis comes from its native ICD-10 field. Content coverage and model-performance evidence remain separate layers.

Included: item-level task, setting, user role, response format, evaluation method, reference standard, condition roles, code provenance, expected answers where available, and public-safe source traceability.
Not included yet: linked item-level model scores or claims of clinical validation. The explorer therefore reports n_scored = 0 and n_label_validated = 0, instead of treating aggregate leaderboard results as disease-specific evidence.
